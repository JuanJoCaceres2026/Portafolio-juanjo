# Juan José Cáceres Huezo - Portfolio

The portfolio website and downloadable résumé are in English.

## Files
- `index.html` - the portfolio website.
- `yooo.jpeg` - profile photo.
- `cv-juan-jose.pdf` - English résumé.

## Publish on GitHub Pages
1. Create a public repository named `portafolio-juanjo` under `JuanJoCaceres2026`.
2. Upload all files in this folder to the repository root.
3. In the repository, open **Settings > Pages**.
4. Choose **Deploy from a branch**, select **main** and **/(root)**, then save.
5. The site address will be `https://juanjocaceres2026.github.io/portafolio-juanjo/` after GitHub finishes publishing.

Keep `index.html`, `yooo.jpeg`, and `cv-juan-jose.pdf` together in the repository root so the photo and résumé links work.
