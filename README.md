# Juan José Cáceres Huezo — Portfolio

The English portfolio is published from the repository root.

## Files
- `index.html` — website
- `yooo.jpeg` — profile photo
- `cv-juan-jose.pdf` — downloadable résumé

## Enable GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose **main** and **/(root)**, then click **Save**.
4. GitHub will publish the site at `https://juanjocaceres2026.github.io/Portafolio-juanjo/`.

Keep the three files above together in the repository root so the photo and résumé links keep working.

## Contact
